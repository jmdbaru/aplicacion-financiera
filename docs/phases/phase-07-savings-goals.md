# Fase 7 — Objetivos de ahorro

Implementación técnica completada en `v1.031`.

- Supabase: objetivos, aportaciones, RLS y RPC de progreso agregado.
- API: creación, cambio de estado y aportaciones bajo el JWT del usuario.
- Web: creación, progreso derivado, historial reciente, cierre y archivo.
- La aportación es un registro independiente; no altera ni duplica el saldo de cuentas.

## Validación funcional pendiente

Crear un objetivo, registrar dos aportaciones, comprobar el progreso y el historial, cerrar el objetivo y archivarlo desde la vista previa publicada.
