# Documentación del proyecto

Esta carpeta es la fuente de verdad técnica de la aplicación financiera.

- `architecture/overview.md`: arquitectura objetivo, dominios y estructura.
- `architecture/database.md`: modelo lógico, invariantes e índices.
- `architecture/security.md`: límites de confianza, RLS y controles.
- `architecture/decisions/`: decisiones arquitectónicas (ADR).
- `phases/`: informes verificables de cada fase.
- `maintenance/`: pruebas, despliegue y diagnóstico.

`PROJECT_STATUS.md` indica qué está realmente implementado.
